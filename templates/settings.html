Gmail

Du meldest dich bei Google an und erlaubst ausschließlich das Lesen deiner Mails.
{% if google %}App-Kennung: {{ google['source'] }} ✓{% else %}Es ist noch keine App-Kennung hinterlegt.{% endif %}
{{ 'Eigene Kennung austauschen' if google else 'Eigene Kennung einrichten' }}
  1. In der Google-Konsole einen Client vom Typ „Desktop-App“ anlegen und die Gmail API aktivieren.
  2. Die Datei client_secret_….json herunterladen und hier auswählen.
Zugang läuft nach 7 Tagen ab?

Das passiert, solange die App in der Google-Konsole unter „Zielgruppe“ im Status „Test“ steht. Stelle sie dort auf „In Produktion“ und verbinde das Konto danach hier erneut. Beim Anmelden zeigt Google dann den Hinweis, dass die App nicht überprüft ist; über „Erweitert“ geht es weiter.

Outlook / Hotmail

Du meldest dich bei Microsoft an und erlaubst ausschließlich das Lesen deiner Mails. Gelesen wird der Posteingang.
{% if microsoft %}App-Kennung: {{ microsoft['source'] }} ✓{% else %}Es ist noch keine App-Kennung hinterlegt. Einmal einrichten, danach reicht der Knopf.{% endif %}
{{ 'Eigene Kennung ändern' if microsoft else 'Kennung einmalig einrichten (etwa 10 Minuten)' }}
  1. Im Microsoft Entra Admin Center unter „App-Registrierungen“ auf „Neue Registrierung“ klicken.
  2. Name frei wählen. Unterstützte Kontotypen: „Konten in einem beliebigen Organisationsverzeichnis und persönliche Microsoft-Konten“.
  3. Umleitungs-URI: Plattform „Öffentlicher Client/nativ (mobil und Desktop)“ und als Adresse {{ ms_redirect }}
  4. Registrieren, dann die „Anwendungs-ID (Client)“ kopieren und hier einfügen. Ein Geheimnis (Client Secret) wird nicht benötigt.

Leer speichern entfernt die eigene Kennung wieder.

Die Anmeldung läuft direkt zwischen deinem Browser und Google bzw. Microsoft. Passwörter sieht diese Anwendung nie. Gespeichert wird nur ein Lesezugang, lokal in private/.
